# WasmDroid

Run WebAssembly apps and local web servers on Android. WasmDroid is a free,
open-source app from ATG Services SRL. It runs compatible packages directly on
your device and requires no WasmDroid account.

## What you can do

- Search the public Wasmer Registry and download compatible packages.
- Run apps and command-line tools locally. Start and stop each service and
  inspect its output.
- Open supported web apps on the phone, or share them over Wi-Fi using an
  address or QR code.
- Monitor CPU and memory usage and set an optional stop timer.
- Keep files in named volumes and configure Internet and local network access
  for each app.

WasmDroid supports Android 9 (API 28) and later. Compatibility depends on the
package version and its runtime requirements.

## Get started

1. Open **Store**, search for a package and download a release.
2. Choose **Create service** and configure the command and any required settings.
3. Open **My apps** and tap **Start**. If a web address appears, open it on your
   phone or from another device on the same Wi-Fi network.
